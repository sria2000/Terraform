# Terraform – AWS EC2 and Multiple AWS Providers

## Scenario

We want to deploy AWS resources in different regions:

* **EC2** → Singapore (`ap-southeast-1`)
* **Security Group / Firewall** → Mumbai (`ap-south-1`)
* Another Security Group → USA (`us-east-1`)

Terraform allows multiple configurations of the same provider, but **additional provider configurations must use aliases**.

---

## Base Code – Incorrect

```hcl
provider "aws" {
  region = "ap-southeast-1"
}

resource "aws_security_group" "allow_tls" {
  name     = "prod_firewall"
  provider = aws.usa
}

resource "aws_security_group" "allow_tls" {
  name     = "staging_firewall"
  provider = aws.mumbai
}
```

### Problems

1. `aws.usa` and `aws.mumbai` have not been defined.
2. Both resources have the same Terraform resource name:

   ```hcl
   aws_security_group.allow_tls
   ```
3. You cannot have two default AWS provider configurations without distinguishing them with aliases.

---

# Final Code – Multiple AWS Providers

```hcl
provider "aws" {
  region = "ap-southeast-1"
}

provider "aws" {
  alias  = "mumbai"
  region = "ap-south-1"
}

provider "aws" {
  alias  = "usa"
  region = "us-east-1"
}

resource "aws_security_group" "sg_1" {
  name     = "prod_firewall"
  provider = aws.usa
}

resource "aws_security_group" "sg_2" {
  name     = "staging_firewall"
  provider = aws.mumbai
}
```

---

## Understanding the Providers

| Provider    | Region    | Reference    |
| ----------- | --------- | ------------ |
| Default AWS | Singapore | `aws`        |
| Mumbai AWS  | Mumbai    | `aws.mumbai` |
| USA AWS     | US East   | `aws.usa`    |

The default provider does **not** need an alias.

Additional configurations require an alias.

---

## How `alias` Works

This configuration:

```hcl
provider "aws" {
  alias  = "mumbai"
  region = "ap-south-1"
}
```

creates a provider configuration called:

```text
aws.mumbai
```

A resource can then explicitly select it:

```hcl
provider = aws.mumbai
```

Therefore:

```text
provider = aws.mumbai
        ↓
AWS Provider
        ↓
ap-south-1
        ↓
Mumbai
```

Similarly:

```text
provider = aws.usa
        ↓
AWS Provider
        ↓
us-east-1
        ↓
USA
```

---

# Key Terraform Rule

### Multiple providers of the same type ARE possible.

The correct statement is:

> **Multiple configurations of the same provider are possible, but additional configurations require an alias.**

For example:

```hcl
provider "aws" {
  region = "ap-southeast-1"
}

provider "aws" {
  alias  = "mumbai"
  region = "ap-south-1"
}
```

Both are AWS providers, but the second one is identified using:

```hcl
aws.mumbai
```

---

# Important Interview Question

### Q: Can Terraform have multiple AWS providers?

**Answer:**

Yes. Terraform supports multiple configurations of the same provider. The default configuration can be used without an alias, while additional configurations must use an `alias`.

Example:

```hcl
provider "aws" {
  region = "ap-southeast-1"
}

provider "aws" {
  alias  = "mumbai"
  region = "ap-south-1"
}
```

A resource can select the Mumbai provider using:

```hcl
provider = aws.mumbai
```


### Syntax

```hcl
provider "aws" {
  alias  = "NAME"
  region = "REGION"
}
```

Then:

```hcl
provider = aws.NAME
```

**Key word to remember: `alias` = distinguish multiple configurations of the same provider.**
